# ASAPH Gate Check-in

คู่มือ Staff หน้างาน ASAPH Event แบบหน้าเว็บมีแอนิเมชัน

- ส่วนที่ 1: เปิดลิงค์สแกน `regito.jetcoding.co/asaph-scan` และสแกน QR
- ส่วนที่ 2: เปิดตั๋วในแอพ ASAPH ของลูกค้า สแกนทุกใบ และนับริสแบรนด์
- ผลสแกน 4 แบบ พร้อมหน้าจอจำลองให้ซ้อม
- ส่วนที่ 3: ขายบัตรหน้างานผ่าน Beam Bolt

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages
